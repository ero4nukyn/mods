# VR Support (мод для Necraft 1.7.7+)

Поддержка VR-шлемов через OpenXR (Windows; SteamVR, Oculus/Meta PC, Windows Mixed Reality и др.). Нужен рантайм OpenXR, выбранный
активным (в SteamVR: Настройки → OpenXR → «Сделать SteamVR активным рантаймом OpenXR»).

## Сборка

```
cd mods-src/vr-support
../../gradlew jar -PgameJar=путь/к/necraft-1.7.7.jar
```

Результат: `build/libs/vr-support.jar` → в папку `mods` игры. Мод **клиентский** (`clientOnly`): на сервере его иметь не нужно, и
остальные игроки его не обязаны ставить. Они видят твои руки и наклон головы сами, без мода.

## Управление

| Что | Кнопка |
|---|---|
| Ходьба | левый стик (по взгляду; `/vr move hand` — по левому контроллеру) |
| Бег | нажать левый стик |
| Поворот | правый стик вбок (щелчок 30°; `/vr snap 45`, плавно — `/vr smooth 120`) |
| Следующий / предыдущий слот | правый стик вверх / вниз |
| Ломать, бить | правый триггер |
| Ставить, использовать | правый хват |
| Прыжок (в полёте — вверх) | A, два быстрых нажатия — полёт (креатив) |
| Присесть (в полёте — вниз) | держать левый хват или присесть в комнате |
| Взять блок | левый триггер |
| Инвентарь | B |
| Чат (клавиатура выезжает снизу) | X |
| Пауза | Y или кнопка меню |
| Пересесть на место (центр комнаты) | нажать правый стик |
| Хотбар и здоровье | панель над левой рукой |
| Меню | панель перед лицом, указка правой рукой: триггер — клик, хват — ПКМ, стик вверх/вниз — прокрутка |
| Ввод текста (чат, имя мира, адрес сервера, пароль, поиск) | когда в экране выбрано текстовое поле, снизу выезжает клавиатура: целься лучом правой руки, триггер или хват — нажать клавишу |
| Наковальня | ПКМ-хват по наковальне открывает режим; палитра предметов висит над левой рукой |

Команда `/vr` в чате показывает и меняет настройки (`snap`, `smooth`, `move`, `vignette`, `scale`, `hand left|right`); они сохраняются.

## Наковальня в VR

Подойди к наковальне и нажми **правый хват** (как ПКМ; левый хват — присед, тогда хват ставит блок). Голова остаётся на месте: ты видишь
наковальню прямо перед собой.

* **Палитра предметов** висит над левой рукой: хотбар, а **левый триггер** раскрывает весь инвентарь. Целься в ячейку лучом правой руки и жми
  правый триггер — предмет «в руке» (в инвентаре остаётся, как и без VR). Стик вверх/вниз листает хотбар.
* **Правая рука** целится в верх наковальни: луч и жёлтая метка показывают, куда ляжет кусок. Метка серая — луч мимо верха.
* **Правый хват** кладёт выбранный приготовленный крамдий (держи — кладёт ещё и ещё), по лежащему куску берёт обратно.
* **Правый триггер** вне палитры с топором в руке — удар (рука завибрирует). Без топора он забирает кусок.
* **B / Y** — выйти из режима. Если вещи остались на наковальне, они вернутся в инвентарь.

## Клавиатура и чат

**X** открывает чат. Как только в экране выбрано текстовое поле (чат, имя мира, адрес сервера, пароль), снизу, под панелью, выезжает
клавиатура, наклонённая к лицу. Раскладки: латиница (EN) и кириллица (РУ), цифры и символы (123/ABC), Shift (одна заглавная) и двойной Shift
(Caps), Backspace с повтором при удержании, пробел, `/` для команд, OK = Enter. Язык раскладки берётся из языка игры. Свежие строки чата
видны плашкой над левым запястьем.

## Пока не умеет

* Только Windows. Linux и macOS: у OpenXR + OpenGL там другая привязка к окну, она не сделана.
* Нет теней (для скорости), эффекта красной вспышки при уроне (вместо него вибрация).
